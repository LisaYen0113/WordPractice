# 資料夾功能（批次 2）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓使用者能建立／改名／刪除自訂資料夾、把單字指派到資料夾，並依資料夾篩選清單與測驗出題範圍。

**Architecture:** 後端只做 CRUD（`folders` 表 + `user_words.folder_id`），篩選完全留在前端 —— `/deck` 本來就是全量載入，切換資料夾不必打 API。資料夾與字是一對多（`NULL` = 未分類），刪資料夾時 DB 的 `ON DELETE SET NULL` 讓裡面的字自動退回未分類，複習進度不動。

**Tech Stack:** FastAPI + pydantic v2（後端）、React 18 + CRA 5（`react-scripts test`）、Supabase/PostgREST（`supabase_request` 薄封裝）、pytest。

**Spec:** `docs/superpowers/specs/2026-10-10-folders-design.md`

## Global Constraints

- **後端 detail 語言規則**（依 `client.js` 的實際行為，不是「一律英文」）：
  - **會透傳給使用者的用中文** —— 400 / 404 / 409 / 502 的 `detail` 前端會直接顯示（`client.js:89,103`）。
  - **會被 `client.js` 蓋掉的用英文** —— 5xx 一律被換成「伺服器發生錯誤，請稍後再試」（`client.js:109`），所以後端 500 的 detail 只給 log 看。
- **每個 DAO 查詢一律帶 `user_id` 範圍**：後端用 service key，會繞過 RLS，DAO 是唯一防線（`user_words_dao.py:64` 的既有註解）。
- **不可變（immutability）**：前端一律回傳新物件／新陣列，不 mutate 輸入。後端不改傳入的 dict。
- **檔案 200–400 行、函式 < 50 行**；不新增任何 npm / pip 依賴。
- **測試命名與斷言一律用繁體中文**，並在註解寫出「這個測試釘住哪個 bug」。
- **限流一律用 `rate_limited(...)` 依賴**，不可自己刻。
- **`redirect_slashes=False`**（`main.py:30`）：collection 根路徑必須寫成 `@router.get("")`，寫 `"/"` 會變成 `/folders/`，而 `/folders` 會 404。
- 每個任務結尾都有 commit 步驟。**若不想留 git 紀錄，執行時跳過 commit 步驟即可，其餘照做。**

## Review Focus

以下是 spec 沒寫到、但真實使用者一定會踩到的行為。每一條都在對應任務裡有測試釘住。

1. **名稱前後空白**：輸入「 TOEIC 」時必須與既有「TOEIC」視為同名 → 409，不能建出兩個看起來一模一樣的資料夾。
2. **在別的分頁刪掉的資料夾**：這個分頁的選單還留著它，指派過去必須回 404「找不到這個資料夾」，不是 500，也不是靜默失敗。
3. **`{"folder_id": null}` 是合法的「移回未分類」**；但 `{}`（整個欄位沒帶）要 422 —— 兩者語意不同，不能都當成取消指派。
4. **名稱全空白或超過 50 字元** → 422，不是 500。
5. **刪掉正在瀏覽的資料夾** → 篩選退回「全部」，畫面不能卡在一個不存在的 id 上變空白。

- [ ] **Step 4: 修補 `user_words` 的 insert / update 政策（安全關鍵）**

**這是這個任務最重要的一步。** 現有政策只驗「這一列屬於呼叫者」，不驗「`folder_id` 指向的資料夾也屬於呼叫者」。加上 `folder_id` 之後，拿 anon/authenticated key 直接打 PostgREST 就能把字塞進別人的資料夾。把現有的 `user_words_insert_own` 與 `user_words_update_own` 兩段（原第 79-90 行）整段換成：

```sql
drop policy if exists "user_words_insert_own" on public.user_words;
create policy "user_words_insert_own"
    on public.user_words for insert
    to authenticated
    with check (
        auth.uid() = user_id
        -- FK 只保證資料夾存在,不保證是我的 → 這裡自己驗
        and (folder_id is null or exists (
            select 1 from public.folders f
            where f.id = folder_id and f.user_id = auth.uid()
        ))
    );

drop policy if exists "user_words_update_own" on public.user_words;
create policy "user_words_update_own"
    on public.user_words for update
    to authenticated
    using (auth.uid() = user_id)
    with check (
        auth.uid() = user_id
        and (folder_id is null or exists (
            select 1 from public.folders f
            where f.id = folder_id and f.user_id = auth.uid()
        ))
    );
```

`user_words_delete_own` 不用改。

- [ ] **Step 1: 寫失敗的測試**

```python
class TestFolderName:
    """資料夾名稱:strip → 1~50 字 → 擋控制字元/零寬/bidi"""

    def test_strips_surrounding_whitespace(self):
        # 「 TOEIC 」與「TOEIC」必須是同一個名字,否則會建出兩個看起來一樣的資料夾
        from app.schemas.folders import FolderCreateRequest

        assert FolderCreateRequest(name="  TOEIC  ").name == "TOEIC"

    @pytest.mark.parametrize("raw", ["", "   ", "\t\n "])
    def test_rejects_blank(self, raw):
        from app.schemas.folders import FolderCreateRequest

        with pytest.raises(ValidationError):
            FolderCreateRequest(name=raw)

    def test_rejects_over_50_chars(self):
        from app.schemas.folders import FolderCreateRequest
```

```python
from fastapi import HTTPException

from app.core.supabase_client import supabase_request

# 只抓前端要用的欄位
_FOLDER_COLUMNS = "id,name,created_at"

_NOT_FOUND = "找不到這個資料夾"


def list_folders(user_id: str):
    return supabase_request(
        "GET",
        "folders",
        params={
            "user_id": f"eq.{user_id}",
            "select": _FOLDER_COLUMNS,
            "order": "created_at.asc",
        },
    )


def create_folder(user_id: str, name: str):
    """建立資料夾;回傳新列(dict)或 None。名稱重複由 DB 的 unique 擋(上游 409)"""
    result = supabase_request(
        "POST",
        "folders",
        data={"user_id": user_id, "name": name},
    )
    # Prefer: return=representation 是 supabase_request 對 POST 的預設 → 回傳 list
    if isinstance(result, list):
        return result[0] if result else None
    return result


def get_folder(user_id: str, folder_id: str):
    """取單一資料夾;不存在或不屬於該使用者都回 None(呼叫端一律轉 404)"""
    result = supabase_request(
        "GET",
        "folders",
        params={
            "user_id": f"eq.{user_id}",
            "id": f"eq.{folder_id}",
            "select": _FOLDER_COLUMNS,
        },
    )
    if isinstance(result, list):
        return result[0] if result else None
    return result


def rename_folder(user_id: str, folder_id: str, name: str):
    """改名。一律帶 user_id 範圍:service key 會繞過 RLS,DAO 是唯一防線。

    scoped PATCH 沒中任何列時 PostgREST 預設靜默回 204 → 要求 representation,
    空結果就是「不是你的資料夾或已刪除」,轉 404。
    """
    result = supabase_request(
        "PATCH",
        "folders",
        params={"id": f"eq.{folder_id}", "user_id": f"eq.{user_id}"},
        data={"name": name},
        prefer="return=representation",
    )
    if not result:
        raise HTTPException(status_code=404, detail=_NOT_FOUND)
    return result[0]


def delete_folder(user_id: str, folder_id: str):
    """刪除。裡面的字由 FK 的 ON DELETE SET NULL 退回未分類,複習進度不動。

    0 列的 DELETE 一樣回 204 → 要求 representation,空結果轉 404。
    """
    result = supabase_request(
        "DELETE",
        "folders",
        params={"id": f"eq.{folder_id}", "user_id": f"eq.{user_id}"},
        prefer="return=representation",
    )
    if not result:
        raise HTTPException(status_code=404, detail=_NOT_FOUND)
    return result[0]
```

```python
# app/services/folders_service.py
import uuid

from fastapi import HTTPException

from app.daos.folders_dao import (
    create_folder,
    delete_folder,
    list_folders,
    rename_folder,
)

# DB 的 unique (user_id, name) 被違反時 PostgREST 回 409,
# 但 supabase_request 的 detail 是刻意通用的 "Database request failed"(避免洩漏 schema)。
# 409 會透傳給使用者(client.js 直接採用 detail)→ 在這裡換成看得懂的中文。
_DUPLICATE_NAME = "已經有同名資料夾"


def _translate_unique_violation(error: HTTPException) -> HTTPException:
    """409(unique violation)→ 中文訊息;其他狀態碼原樣往上拋"""
    if error.status_code == 409:
        return HTTPException(status_code=409, detail=_DUPLICATE_NAME)
    return error


def get_folders(user_id: uuid.UUID) -> list:
    return list_folders(str(user_id))


def add_folder(user_id: uuid.UUID, name: str) -> dict:
    try:
        row = create_folder(str(user_id), name)
    except HTTPException as error:
        raise _translate_unique_violation(error) from error
    if not row:
        # 上游回空 representation(不該發生) → 500 的 detail 只給 log 看,用英文
        raise HTTPException(status_code=500, detail="Failed to create folder")
    return row
```

```js
// 資料夾篩選。純函式、不改輸入。
// selection 有三態:"all" | "uncategorized" | 某個資料夾的 id

export const ALL_FOLDERS = "all";
export const UNCATEGORIZED = "uncategorized";

export function filterByFolder(words, selection) {
  if (selection === ALL_FOLDERS) {
    return words;
  }
  if (selection === UNCATEGORIZED) {
    return words.filter((word) => !word.folderId);
  }
  return words.filter((word) => word.folderId === selection);
}

// chip 上的字數。前端手上已有完整 deck(上限 200 筆),自己算就好,不必多打 API
export function countByFolder(words) {
  return words.reduce((counts, word) => {
    const key = word.folderId ?? UNCATEGORIZED;
    return { ...counts, [key]: (counts[key] ?? 0) + 1 };
  }, {});
}
```

```js
export function validateFolderName(raw) {
  if (typeof raw !== "string") {
    return { ok: false, error: "請先輸入資料夾名稱" };

  if (!value) {
    return { ok: false, error: "請先輸入資料夾名稱" };
```

```js
import { useCallback, useEffect, useMemo, useRef, useState } from "react";

import { createFolder, deleteFolder, fetchFolders, renameFolder } from "../api/folders";
import { apiErrorMessage } from "../utils/errors";
import { validateFolderName } from "../utils/validation";

/**
 * 資料夾清單資料層:
 * - 初次 mount 抓 GET /folders
 * - 舊請求晚回來時丟棄(React 19 StrictMode 會雙跑 effect,也用同一機制防護)
 * - 寫入以伺服器回傳值為準;失敗保留原狀 + actionError,並回 false 讓呼叫端決定後續
 */
export default function useFolders() {
  const [status, setStatus] = useState("loading");
  const [folders, setFolders] = useState([]);
  const [error, setError] = useState(null);
  const [actionError, setActionError] = useState(null);
  const [pending, setPending] = useState(false);

  const requestIdRef = useRef(0);

  const load = useCallback(async () => {
    requestIdRef.current += 1;
    const requestId = requestIdRef.current;
    setStatus("loading");
    setError(null);
    try {
      const rows = await fetchFolders();
      if (requestIdRef.current !== requestId) {
        return;
      }
      setFolders(rows.map((row) => ({ id: row.id, name: row.name })));
      setStatus("ready");
    } catch (err) {
      if (requestIdRef.current !== requestId) {
        return;
      }
      setError(apiErrorMessage(err, "載入資料夾失敗,請稍後再試"));
      setStatus("error");
    }
  }, []);

  useEffect(() => {
    load();
    return () => {
      // 作廢所有進行中的請求(unmount 或 StrictMode 的第一次 effect)
      requestIdRef.current += 1;
    };
  }, [load]);

  // 三個寫入共用同一段流程:驗證 → 打 API → 更新清單 → 回報成功與否
  const runWrite = useCallback(async (action) => {
    setPending(true);
    setActionError(null);
    try {
      await action();
      return true;
    } catch (err) {
      setActionError(apiErrorMessage(err));
      return false;
    } finally {
      setPending(false);
    }
  }, []);

  const addFolder = useCallback(
    (name) => {
      const checked = validateFolderName(name);
      if (!checked.ok) {
        // 前端預檢擋掉明顯無效的輸入,免得白打一趟 422
        setActionError(checked.error);
        return Promise.resolve(false);
      }
      return runWrite(async () => {
        const row = await createFolder(checked.value);
        setFolders((prev) => [...prev, { id: row.id, name: row.name }]);
      });
    },
    [runWrite]
  );

  const renameFolderById = useCallback(
    (folderId, name) => {
      const checked = validateFolderName(name);
      if (!checked.ok) {
        setActionError(checked.error);
        return Promise.resolve(false);
      }
      return runWrite(async () => {
        const row = await renameFolder(folderId, checked.value);
        setFolders((prev) =>
          prev.map((folder) =>
            folder.id === folderId ? { ...folder, name: row.name } : folder
          )
        );
      });
    },
    [runWrite]
  );

  const removeFolder = useCallback(
    (folderId) =>
      runWrite(async () => {
        await deleteFolder(folderId);
        setFolders((prev) => prev.filter((folder) => folder.id !== folderId));
      }),
    [runWrite]
  );

  return useMemo(
    () => ({
      status,
      folders,
      error,
      reload: load,
      pending,
      actionError,
      addFolder,
      renameFolderById,
      removeFolder,
    }),
    [
      status,
      folders,
      error,
      load,
      pending,
      actionError,
      addFolder,
      renameFolderById,
      removeFolder,
    ]
  );
}
```

```jsx
import React, { useState } from "react";

import { ALL_FOLDERS, UNCATEGORIZED } from "../utils/folders";

// 選中的 chip 樣式;與 Tabs 的選中態一致
const ACTIVE =
  "bg-zinc-900 dark:bg-white text-white dark:text-[#0d1410] border-transparent";
const INACTIVE =
  "bg-white dark:bg-[#122017] text-zinc-600 dark:text-zinc-300 border-zinc-200 dark:border-[#29382f] hover:bg-zinc-100 dark:hover:bg-[#29382f]";

function Chip({ label, count, active, onClick }) {
  return (
    <button
      onClick={onClick}
      className={`shrink-0 flex items-center gap-1.5 px-3 py-1.5 rounded-full border text-sm font-bold transition-all duration-200 ${active ? ACTIVE : INACTIVE}`}
    >
      <span className="max-w-[8rem] truncate">{label}</span>
      <span className="text-xs font-mono opacity-70">{count}</span>
    </button>
  );
}

/**
 * 資料夾選擇器:橫向可捲動的 chip 列 + 最右邊的新增入口。
 * 篩選完全在前端做,這裡只回報選了哪一個。
 */
export default function FolderBar({
  folders = [],
  selection,
  onSelect,
  onEdit,
  counts = {},
  onCreate,
  pending = false,
  actionError = null,
}) {
  const [adding, setAdding] = useState(false);
  const [draft, setDraft] = useState("");

  const total = Object.values(counts).reduce((sum, n) => sum + n, 0);
  const uncategorizedCount = counts[UNCATEGORIZED] ?? 0;
  const trimmed = draft.trim();

  const submit = async () => {
    if (!trimmed) return;
    const ok = await onCreate(trimmed);
    // 失敗時保留輸入,讓使用者改一個字就能重試
    if (ok) {
      setDraft("");
      setAdding(false);
    }
  };

  return (
    <div className="flex flex-col gap-2 w-full">
      <div className="flex items-center gap-2 overflow-x-auto pb-1 -mb-1">
        <Chip
          label="全部"
          count={total}
          active={selection === ALL_FOLDERS}
          onClick={() => onSelect(ALL_FOLDERS)}
        />
        <Chip
          label="未分類"
          count={uncategorizedCount}
          active={selection === UNCATEGORIZED}
          onClick={() => onSelect(UNCATEGORIZED)}
        />
        {folders.map((folder) => (
          <React.Fragment key={folder.id}>
            <Chip
              label={folder.name}
              count={counts[folder.id] ?? 0}
              active={selection === folder.id}
              onClick={() => onSelect(folder.id)}
            />
            {/* 編輯入口只跟著選中的 chip 出現 —— chip 本身是 button,
                不能把 button 疊進 button,所以放成兄弟節點 */}
            {selection === folder.id && (
              <button
                onClick={() => onEdit(folder.id)}
                aria-label={`編輯 ${folder.name}`}
                className={`shrink-0 px-2.5 py-1.5 rounded-full border text-sm font-bold transition-all duration-200 ${INACTIVE}`}
              >
                ⋯
              </button>
            )}
          </React.Fragment>
        ))}
        <button
          onClick={() => setAdding((prev) => !prev)}
          aria-label="新增資料夾"
          className={`shrink-0 px-3 py-1.5 rounded-full border border-dashed text-sm font-bold transition-all duration-200 ${INACTIVE}`}
        >
          ＋
        </button>
      </div>

      {adding && (
        <div className="flex items-center gap-2">
          <input
            value={draft}
            onChange={(event) => setDraft(event.target.value)}
            onKeyDown={(event) => {
              if (event.key === "Enter") submit();
            }}
            placeholder="資料夾名稱"
            maxLength={50}
            className="flex-1 min-w-0 px-3 py-2 rounded-xl border border-zinc-200 dark:border-[#29382f] bg-white dark:bg-[#122017] text-sm text-zinc-900 dark:text-zinc-100"
          />
          <button
            onClick={submit}
            disabled={!trimmed || pending}
            className="shrink-0 px-4 py-2 rounded-xl bg-zinc-900 dark:bg-white text-white dark:text-[#0d1410] text-sm font-bold disabled:opacity-40 disabled:cursor-not-allowed"
          >
            建立
          </button>
        </div>
      )}

      {actionError && (
        <p role="alert" className="text-sm font-medium text-red-600 dark:text-red-400">
          {actionError}
        </p>
      )}
    </div>
  );
}
```

```jsx
import React, { useState } from "react";

/**
 * 管理單一資料夾:改名 / 刪除。
 * 刪除走二次確認,而且文案要明講字會退回未分類、進度不會消失 ——
 * 這是使用者最怕按錯的一顆按鈕。
 */
export default function FolderEditor({
  folder,
  onRename,
  onDelete,
  onClose,
  pending = false,
  actionError = null,
}) {
  const [name, setName] = useState(folder.name);
  const [confirmingDelete, setConfirmingDelete] = useState(false);

  const trimmed = name.trim();

  const submitRename = async () => {
    if (!trimmed) return;
    if (await onRename(trimmed)) {
      onClose();
    }
  };

  const submitDelete = async () => {
    if (await onDelete()) {
      onClose();
    }
  };

  return (
    <div className="fixed inset-0 z-[70] flex items-center justify-center bg-black/40 backdrop-blur-sm p-4">
      <div className="w-full max-w-sm bg-white dark:bg-[#122017] rounded-2xl shadow-2xl border border-zinc-200 dark:border-[#29382f] p-4 flex flex-col gap-3">
        {confirmingDelete ? (
          <>
            <h2 className="text-base font-bold text-zinc-900 dark:text-white">
              刪除「{folder.name}」?
            </h2>
            <p className="text-sm text-zinc-500 dark:text-zinc-400">
              刪除後,裡面的字會回到「未分類」,複習進度不會消失。
            </p>
            <div className="flex gap-2 mt-1">
              <button
                onClick={() => setConfirmingDelete(false)}
                className="flex-1 h-11 rounded-xl border border-zinc-200 dark:border-[#29382f] text-zinc-600 dark:text-zinc-300 font-bold hover:bg-zinc-50 dark:hover:bg-[#29382f] transition-colors"
              >
                取消
              </button>
              <button
                onClick={submitDelete}
                disabled={pending}
                className="flex-1 h-11 rounded-xl bg-red-600 text-white font-bold hover:bg-red-700 disabled:opacity-50 transition-colors"
              >
                確定刪除
              </button>
            </div>
          </>
        ) : (
          <>
            <h2 className="text-sm font-bold text-zinc-400 dark:text-zinc-500 uppercase tracking-wider">
              編輯資料夾
            </h2>
            <input
              value={name}
              onChange={(event) => setName(event.target.value)}
              onKeyDown={(event) => {
                if (event.key === "Enter") submitRename();
              }}
              placeholder="資料夾名稱"
              maxLength={50}
              className="px-3 py-2 rounded-xl border border-zinc-200 dark:border-[#29382f] bg-white dark:bg-[#122017] text-sm text-zinc-900 dark:text-zinc-100"
            />
            <button
              onClick={submitRename}
              disabled={!trimmed || pending}
              className="h-11 rounded-xl bg-zinc-900 dark:bg-white text-white dark:text-[#0d1410] font-bold disabled:opacity-40 disabled:cursor-not-allowed transition-colors"
            >
              儲存
            </button>
            <button
              onClick={() => setConfirmingDelete(true)}
              disabled={pending}
              className="h-11 rounded-xl border border-red-200 dark:border-red-900/40 text-red-600 dark:text-red-400 font-bold hover:bg-red-50 dark:hover:bg-red-900/20 disabled:opacity-50 transition-colors"
            >
              刪除資料夾
            </button>
            <button
              onClick={onClose}
              className="h-11 rounded-xl border border-zinc-200 dark:border-[#29382f] text-zinc-600 dark:text-zinc-300 font-bold hover:bg-zinc-50 dark:hover:bg-[#29382f] transition-colors"
            >
              取消
            </button>
          </>
        )}

        {actionError && (
          <p role="alert" className="text-sm font-medium text-red-600 dark:text-red-400">
            {actionError}
          </p>
        )}
      </div>
    </div>
  );
}
```
